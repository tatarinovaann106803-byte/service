Готовое обновление сервиса RU/EN, RUB/USD и страновые CAPEX.

Скопируйте содержимое архива в корень репозитория с заменой соответствующих файлов. Сохраните свои настройки renderUrl и yandexApiKey в integrations/tilda.html. Загрузите изменения в GitHub и повторно разверните сервер. На английской странице Тильды задайте language: en и currency: USD в CONFIG (строковые значения в кавычках). Полная инструкция: docs/LOCALIZATION_AND_COSTS_RU.md.

На действующий сайт изменения автоматически не загружены.
