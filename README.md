# Агривольтаика: продукция, энергия, доход

Температура и осадки загружаются из NASA за выбранные месяцы; ручной ввод сохранён как явная альтернатива.

Текущая версия подбирает приближённое множество компромиссных вариантов по трём целям: продуктивность, годовая выработка электроэнергии и экономические показатели. Пользователь сравнивает предложенные варианты и явно выбирает подходящий. Автоматического выбора «единственного оптимума» нет.

На сайте энергетическая часть содержит только установленную мощность и годовую выработку. Геометрия, число панелей, исходные коэффициенты и внутренние расчёты хранятся на сервере и доступны в закрытом калькуляторе владельца. Они не входят в публичный JSON, OpenAPI или выгрузку пользователя.

Это предварительное сценарное сравнение. Связь геометрии, микроклимата и биологического отклика реализована, но не прошла полевую валидацию. Средние по строкам базы используются как индивидуальные ориентиры, а не доказанный причинный эффект панелей. Подробности: [методика](docs/METHODOLOGY_RU.md), [аудит](docs/AUDIT_RU.md).

## Расчёт

Модуль: 610 Вт, 2382 × 1134 мм, КПД ≈ 22,58%. Выработка рассчитывается через площадь модулей, облучение наклонной поверхности с учётом затенения, КПД и совокупные эксплуатационные потери.

- NSGA-II: недоминируемая сортировка, crowding distance, турнирный отбор, SBX, полиномиальная мутация и элитизм. По умолчанию 32 особи, 16 поколений, seed 42; отображаются до 12 разнесённых вариантов.
- Геометрия влияет на затенение, распределение света, сценарное охлаждение и испарение, продуктивность, мощность, выработку и стоимость конструкции.
- Индивидуальные средние значения продуктивности считаются по числовым строкам конкретной культуры/вида. Позже подключим нейросетевую модель (пока недостаточно данных)
- Базовая продуктивность для культур берётся из локального файла FAO: подходящая страна, последний год, проверенные единицы; либо вводится вручную. Для рыбы и древесины файлы содержат общие объёмы без площади, поэтому продуктивность на гектар вводится вручную. 
- Стоимость капитала: прямая ставка или WACC. Финансовая цель — NPV, учитывающий вложения, стоимость капитала, дополнительный доход, OPEX и деградацию выработки. Отдельно показан прирост денежного потока первого года.
- Полив: сезонный водный баланс, экономия м³ и рублей. Заморозки, засуха, град: раздельные вероятность и тяжесть потерь; вводимые защитные эффекты являются сценарными предельными значениями. По умолчанию риски не монетизируются.
- Каждый показанный вариант проверяется на 3 погодных × 3 экономических сценариях. Число сценариев с неотрицательным NPV не является вероятностью успеха. Проверка устойчивости не заменяет пользовательский выбор и не является отдельной робастной оптимизацией.

## Структура и проверка

`agrivoltaic/`: `api.py` и `public_schemas.py` — публичный контракт; `optimization.py`, `nsga2.py`, `physical_scenario.py` — поиск и связанные расчёты; `coefficients.py`, `catalogs.py`, `ingestion.py`, `weather.py` — данные; `economics.py`, `agronomy.py` — экономика, вода и риски; `storage.py` — сохранение публичных расчётов; `owner.py` — защищённый калькулятор с полными конфигурациями. `static/` — интерфейс без внешних CDN; `tests/` — проверки; `docs/` — методика и аудит.
